# SoftANC · 软件反相音频实验台

Windows 桌面实验程序：麦克风输入 → 增益及极性反转 → 有线耳机输出。
这是低延迟反相监听原型，不是已经校准或验证降噪效果的耳机 ANC 产品。

## 启动

设置更改后会自动保存到程序目录的 `settings.json`（滑块停止调整约 350 ms 后写入），关闭窗口时也会保存。下次启动恢复音频设备、采样率、缓冲、延时、独占模式、增益、反相开关和音量阈值设置。设备按名称及音频后端匹配，已断开的设备需重新选择；不会自动开始播放，也不保存耳机音量确认勾选。配置文件损坏时使用默认设置并显示提示。

双击 `Start.cmd`。首次需要 Python 3.11 或更新版本、网络连接以安装依赖；本项目已在本机建立 `.venv`。
也可以运行 `.\.venv\Scripts\python.exe app.py`。

1. 选择真实麦克风和耳机端点，优先选同一声卡、相同 Windows WASAPI 后端。避免蓝牙和扬声器。
2. 从 48000 Hz、缓冲 0、延时 0、增益 5% 开始；先降低 Windows 和耳机音量，再勾选确认并开始。
3. 驱动支持时可停止后勾选 WASAPI 独占模式重试。独占失败会明确报错，不会静默改用高延迟后端。
4. 点击停止或按 Esc 立即中止输出。关闭窗口释放设备。运行时设备参数锁定，增益和反相可实时调节。
5. 出现断续时提高缓冲；额外延时只供窄带实验，无法让系统提前输出。请勿把最小缓冲数当成最小端到端延迟。

### 音量阈值

默认启用，阈值为 **-30 dBFS**，可在运行时通过滑块调整（-80 至 0 dBFS）或关闭。
以输入第一个声道、增益处理前的每个音频块绝对峰值判断：低于阈值正常反相；达到或超过阈值时整块静音，不播放原声。负数越小（例如 -50）越容易触发，越接近 0 越难触发。
触发后保持静音至少 200 ms（按回调块取整），再次超阈值重新计时；恢复时平滑增加增益。静音同时清空额外延时缓存，避免语音稍后从缓存中输出。触发时立即静音可能有轻微切换声，但不会为淡出而继续播放超阈值音频。

可观察输入峰值，把阈值调到环境噪声峰值之上、说话峰值之下。界面显示门控状态。这个功能只按音量判断，不是真正的语音识别：大声噪声也会被静音，轻声说话或未超阈值的语音开头仍可能被输出。门控针对整段混合信号，无法在说话时单独保留背景噪声的反相输出。dBFS 是数字电平，不是环境声压分贝。

只处理麦克风第一个输入通道，同一反相信号输出到耳机左右声道；不做双耳独立声学校准。无录音保存、网络上传或后台自动启动。

## 为什么简单反相不等于 ANC

耳膜处的噪声和耳机反相信号必须幅度、相位同时匹配。麦克风位置与耳膜不同，麦克风、ADC、系统缓冲、DAC、耳机及声学传播都会改变传递函数。直接取负只在数字采样上实现极性翻转。

对于频率 f 的正弦波，假设两路振幅相同、路径除延时 τ 外完全一致，反相后的残余振幅相对原噪声为 `2 |sin(π f τ)|`。例如 100 Hz 下 5 ms 的延迟可能把振幅加倍而不是抵消。宽带随机噪声不能靠单一延时旋钮解决。

本程序未实现误差麦克风、次级声学路径辨识、FxLMS 自适应控制或未来噪声预测。要做有效 ANC，通常需要靠近耳内的误差传感器、合理布置的参考麦克风和可控的低延迟声学/硬件链路。效果必须通过耳内测量验证，不能从波形反向推断。

## 实现与延迟

- PortAudio / sounddevice 单一全双工回调，避免应用层采集与播放队列。
- float32 数据、预分配主要 DSP 工作区；默认不额外延时，不使用 FFT 分帧算法。
- 默认 `latency='low'`、`blocksize=0` 让驱动选择缓冲；可手动尝试 64–512 帧。
- 增益以约 20 ms/单位变化率平滑，启动从零开始；极性反转也经过平滑。
- 输出数字峰值限制在 ±0.25（约 -12 dBFS）；这不是声压限值，也不保证不会啸叫。
- 显示驱动报告的输入/输出延迟、ADC/DAC 回调时间戳跨度、回调负载和缓冲异常次数；不伪装成实测声学延迟。
- Python 与桌面操作系统不是硬实时环境；处理回调仍涉及解释器和少量临时对象。不能承诺某个毫秒数。

官方接口说明：[Stream / 缓冲与延迟](https://python-sounddevice.readthedocs.io/en/latest/api/streams.html)、[WASAPI 独占设置](https://python-sounddevice.readthedocs.io/en/latest/api/platform-specific-settings.html)。

## 检查

运行 `.\.venv\Scripts\python.exe -m unittest -v`，验证极性、左右声道、变长块延时连续性、平滑和输出限幅。
硬件效果需用户戴耳机并在低音量环境自行测试；程序测试不会自动打开麦克风或播放声音。
